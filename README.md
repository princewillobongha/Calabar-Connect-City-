# Calabar Connect City

A premium Calabar community and local-vendor marketplace.

## Planned platform
- Community member and vendor accounts
- Local vendor discovery, product/menu listings, availability and reviews
- Friend requests, profiles, public/private groups and real-time messaging
- Supabase authentication, database, storage and realtime
- Mobile-first interface with restrained motion and performance-conscious visual effects

This repository is being initialized for the Calabar Connect City project. Keep its Supabase project separate from all other sites.
